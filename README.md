# LLM Escape Room — The Locked Science Lab

A solo detective game with seven connected activities, a saved Case File, and an editable final reflection.

Play at https://qingwanceceliacheng.github.io/llm-escape-room/. The older `/public/` address redirects to the game.

GitHub Pages publishes the root of the main branch. Edit the files in this repository, then commit and push to update the site. No production server or API keys are required.

For an optional local preview, use Node.js 20+ and run `npm start`, then open http://localhost:3000. Run `npm test` for the current game checks.

Progress and reflections are saved in the player’s browser. Escape Room resets the full experience.
